## Goal-Based Financial Planning Dashboard (Power BI)

An interactive Power BI dashboard that helps plan client financial goals using model portfolios.

## Features
- **Planning overview page:** shows goals against projected outcomes, with what-if sliders to change assumptions and see projections update instantly
- **Rebalancing page:** a drill-through view for reviewing and rebalancing the model portfolio

## Tools
Power BI, DAX, Excel
